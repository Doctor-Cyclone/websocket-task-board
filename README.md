# WebSocket Task Board

Учебная совместная доска задач на React. Развиваем один проект от обычного подключения WebSocket до синхронизации задач между участниками.

## Первый этап: каркас

Подготовлены React с JavaScript/JSX, Vite, ESLint, Prettier, настройки редактора и GitHub Actions. Стартовый экран проверяет, что React запускается. WebSocket и сервер добавим на следующем учебном шаге.

## Запуск

Нужны Node.js 22.13+ (рекомендуется 24) и pnpm 11.25.0.

```sh
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://127.0.0.1:5174/. Для остановки нажмите Ctrl+C. Порт отличается от прежнего проекта чата.

## Команды

| Команда             | Назначение                                      |
| ------------------- | ----------------------------------------------- |
| `pnpm dev`          | Запустить разработку с обновлением страницы     |
| `pnpm lint`         | Проверить JavaScript, JSX и правила React hooks |
| `pnpm lint:fix`     | Исправить автоматически исправляемые замечания  |
| `pnpm format`       | Отформатировать файлы                           |
| `pnpm format:check` | Проверить форматирование                        |
| `pnpm build`        | Собрать приложение в `dist/`                    |
| `pnpm preview`      | Проверить сборку на http://127.0.0.1:4174/      |
| `pnpm check`        | Выполнить lint, format:check и build            |

ESLint проверяет ошибки и правила React, а Prettier отвечает за оформление. `eslint-config-prettier` отключает конфликтующие правила. В VS Code рекомендуемые расширения указаны в `.vscode/extensions.json`; устанавливаются пользователем.

## Структура

```text
src/
  App.jsx           # Следующий урок начнём прямо здесь
  main.jsx          # Точка входа React и StrictMode
  styles.css        # Минимальное оформление
docs/LEARNING_PLAN.md
eslint.config.js    # Правила JavaScript и React
vite.config.js      # Сборка и локальные порты
.github/workflows/ci.yml
```

Точные зависимости закреплены в `pnpm-lock.yaml`. `.env`, зависимости и сборка не хранятся в Git.

## Как учимся

На каждом шаге: задача → небольшое изменение → цепочка вызовов → проверка в браузере → эксперимент со сбоем. Обёртки вводим после знакомства с прямым API и объясняем, какую проблему они решают. Каждый завершённый этап — отдельный коммит.

[План обучения](docs/LEARNING_PLAN.md). На фронте используем встроенный браузерный WebSocket; библиотеку `ws` для сервера установим, когда начнём подключение.
